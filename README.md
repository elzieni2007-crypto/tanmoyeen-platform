# منصة فرص تنمويين مصر – حسابات الجمعيات

- `index.html`: صفحة دخول الجمعيات وإدارة الفريق (مدير الحساب / مُعِد / مراجع).
- `app.html`: منصة الفرص نفسها لكل جمعية: الفرص بنسبة التوافق، تحليل الفرصة وقرار التقدم، دليل الممولين، المقترح بالعربي والإنجليزي وإيميل التقديم، الموازنة والمرفقات.
- `functions/`: دالة `fpai` اللي بتكلم Claude API. المفتاح محفوظ في Google Secret Manager باسم `ANTHROPIC_API_KEY`، ومش موجود في الكود.
- `.github/workflows/deploy-functions.yml`: بينشر الدالة لوحده كل ما يتغير ملف في `functions/`.

## أين تتخزن البيانات (Firestore)
- `fp_opps` و`fp_funders` و`fp_meta`: الفرص والممولين المشتركين. بتكتبهم المزامنة اليومية بس، وأي جمعية اشتراكها ساري تقراهم.
- `orgs/{orgId}/fp`، `fp_opps`، `fp_proposals`، `fp_guides`: شغل كل جمعية (الملف التعريفي، القرار، الفكرة، الموازنة، المقترحات). محدش يشوفه غير فريق الجمعية والأدمن.
- `fp_usage`: استهلاك الذكاء الاصطناعي لكل جمعية في الشهر. بتكتبه الدالة، والأدمن بس يقراه.

القواعد نفسها في repo الموقع الرئيسي (`firestore.rules`).
